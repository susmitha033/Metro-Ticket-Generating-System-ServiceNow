# Execution Roadmap

The Metro Ticket Generating System will be developed in different stages to ensure smooth implementation and proper testing.

## Project Milestones

### Milestone 1 – Catalog Form Setup
- Create a Service Catalog item for metro ticket booking.
- Configure all required variables such as Source Station, Destination Station, Passenger Type, and Number of Tickets.

### Milestone 2 – Fare Logic Implementation
- Develop the logic to calculate ticket fare automatically based on the selected journey.

### Milestone 3 – QR Code Integration
- Generate a unique QR code after successful ticket booking.
- Use the QR code as the passenger's digital ticket.

### Milestone 4 – Station Details Mapping
- Configure metro station information required for ticket booking and fare calculation.

### Milestone 5 – UI Development
- Design user-friendly pages for ticket booking and ticket details.

### Milestone 6 – User Acceptance Testing (UAT) and Deployment
- Test all functionalities.
- Fix identified issues.
- Deploy the application after successful testing.
