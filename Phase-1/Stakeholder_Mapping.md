# Stakeholder Mapping

The success of the Metro Ticket Generating System depends on the involvement of different stakeholders. Each stakeholder has a specific role in the system.

## Stakeholders

### 1. Passengers (End Users)
- Book metro tickets through the Service Catalog.
- View the generated QR code ticket.
- Use the digital ticket for travel.

### 2. Station Managers
- Verify QR code tickets at metro stations.
- Assist passengers when required.
- Monitor ticket validation activities.

### 3. Metro Operations Team
- Manage station and route information.
- Monitor daily ticket operations.
- Ensure smooth functioning of metro services.

### 4. IT Administrators
- Maintain the ServiceNow application.
- Manage user access and system configurations.
- Resolve technical issues and perform system maintenance.
