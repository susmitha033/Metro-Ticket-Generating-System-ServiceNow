# Functional Scope

The Metro Ticket Generating System is designed to automate the metro ticket booking process using ServiceNow. The system focuses on providing a simple, fast, and digital ticketing experience for passengers.

## Scope of the System

### Ticket Booking
- Allow passengers to book metro tickets through a Service Catalog item.
- Capture booking details such as Source Station, Destination Station, Passenger Type, and Number of Tickets.

### Fare Calculation
- Calculate the ticket fare automatically based on the selected journey details.
- Display the total fare before confirming the booking.

### QR Code Generation
- Generate a unique QR code for every successful ticket booking.
- Use the QR code as the passenger's digital ticket for travel.

### Digital Record Management
- Store ticket booking details securely in the system.
- Maintain booking records for future reference and reporting.
